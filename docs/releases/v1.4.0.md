# Dictum 1.4.0 for Windows

Dictum now offers guided cloud setup and downloadable on-device speech recognition. Choose **Start easily** for OpenRouter, **On this computer** for a native local model, or **Explore other options** for another service or your own server.

## Download

- **`Dictum_1.4.0_x64-setup.exe`**: recommended installer for Windows 10/11 x64.
- **`Dictum_1.4.0_x64_en-US.msi`**: alternative installer for managed deployment.
- **`SHA256SUMS.txt`**: SHA-256 checksums for both installers.
- The `.sig` files and `latest.json` support automatic updates; they are not separate installers.

**The installers do not have a Windows Authenticode publisher signature.** Windows may display an unknown-publisher warning, and Smart App Control or organizational policy may block installation. Tauri's existing cryptographic update signatures remain enabled. Do not disable antivirus protection to run Dictum. See the [signing policy](https://github.com/Vkandil/dictum/blob/main/docs/code-signing-policy.md).

## Local models included in setup

The native inference engines are included in the Windows package. Model weights download separately from **On this computer**, with progress, pause/resume, integrity checks, storage management and verified import. No Python, Docker, account or manually launched server is required for these presets:

- Whisper Tiny, Base and Small;
- Whisper Large v3, Large v3 Turbo and Turbo Q5;
- Parakeet TDT 0.6B v3 INT8;
- Qwen3-ASR 0.6B INT8;
- Moonshine Tiny INT8 for English;
- Nemotron 3.5 ASR streaming INT8 for local Live mode.

The model cards show supported languages, download sizes, estimated memory and licences. **CPU inference is the packaged default.** GPU acceleration requires a separate source build and hardware validation. Voxtral, Qwen 1.7B, Canary, Cohere, Granite and SenseVoice can use compatible external servers; they are not additional managed native downloads. See the [local model guide](https://github.com/Vkandil/dictum/blob/main/docs/local-models.md).

## Providers and first run

- Twenty catalogue entries cover cloud providers, compatible local servers and native inference. Direct services include OpenAI, Groq, Mistral, ElevenLabs, Deepgram, AssemblyAI and Soniox, with additional providers in Explore.
- Setup guides you through provider/model selection, microphone and shortcut configuration, then a real test dictation. Interface language and spoken language are separate, with French and English available for the main interface.
- Transcription, optional AI cleanup and Live connections have separate settings. A local model does not require a cloud API key. Hosted services may require a paid account or credits.
- Credentials use Windows Credential Manager. Audio stays in memory. Local-to-cloud recovery requires explicit consent, and unknown inference costs are displayed as unknown.
- The CLI supports local model management and transcription alongside the desktop application.

## Validation and known limits

The frontend suite has 18 tests and the Rust suite has 62 tests, including the 75-second audio regression and provider contracts. Five native engine families have transcribed a public speech sample on CPU. These checks establish execution, not comparative French accuracy or a WER ranking.

Real paid-cloud accounts, native GPU acceleration, installation/update/uninstall on clean Windows 10/11 profiles and Smart App Control enforcement remain separate acceptance checks. The unsigned packages do not claim to pass enforced Smart App Control. Keep these limits in mind when deploying to other users.
