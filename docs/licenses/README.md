# Native transcription notices

The Windows package redistributes whisper.cpp (MIT), whisper-rs (Unlicense), sherpa-onnx (Apache 2.0) and ONNX Runtime (MIT). Their licence texts and ONNX Runtime's third-party notices are included in this directory and in the installer.

The Sherpa C API and ONNX Runtime are pinned to the native release selected by `sherpa-onnx-sys = 1.13.8`. Model weights are downloaded separately and retain their own licences, shown in the model catalogue. Where a weight archive contains licence and attribution files, Dictum preserves them during installation. The application licence does not replace model licences or hosted-service terms.
